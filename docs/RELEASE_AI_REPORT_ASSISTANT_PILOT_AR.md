# مساعد التقرير بالذكاء الاصطناعي — Pilot

**التاريخ:** 2026-10-17  
**النطاق:** زر «🤖 اسأل» داخل «تقاريري» + Endpoint سحابي `POST /v1/ai/report-chat`.

## الهدف
شرح تقرير تشخيص محفوظ والإجابة عن أسئلة المالك حوله باستخدام Google Gemini من جهة الخادم فقط، مع بقاء تقرير القواعد الحتمي هو المرجع الأساسي.

## ما تم بناؤه
- الـ Worker يتحقق من جلسة المستخدم، ثم يتحقق أن التقرير مملوك له قبل قراءة أي سياق.
- السياق المسموح فقط: ملخص التقرير، findings، مقتطف سجل منقح ومختصر، بيانات سيرفر غير سرية وحالته وبيئته الأساسية.
- تنقية إضافية قبل إرسال السياق إلى Gemini: IPs، الإيميلات، JWT، توكنات البلجن، كلمات السر، روابط قواعد البيانات وروابط Discord webhooks.
- تعليمات صارمة للمساعد: السجل بيانات غير موثوقة لا تعليمات، لا اختراع سبب، لا طلب أسرار، لا ادعاء تنفيذ أي تعديل.
- حد استخدام مؤقت: 30 سؤالًا/ساعة لكل مستخدم/IP داخل ذاكرة الـ Worker، ومهلة 15 ثانية لطلب Gemini.
- أكواد دعم مستقرة: `CM-AI-001` غير مفعّل، `CM-AI-002` غير متاح مؤقتًا، `CM-AI-401` جلسة، `CM-AI-404` تقرير غير موجود/غير مملوك، `CM-AI-422` سؤال غير صالح، `CM-AI-429` حد الاستخدام.
- واجهة اللوحة تعرض الإجابة ونفس findings المحفوظة كدليل، وتوضح أن أي تعديل لم يُنفذ.

## ما لا يفعله
- لا ينفذ أوامر أو يعدل ملفات أو إعدادات سيرفر.
- لا يقرأ سجلات خام كاملة، ولا يطلب باسوردات أو أكواد ربط أو مفاتيح.
- لا يستبدل التشخيص الحتمي؛ عند غياب Gemini يبقى التقرير المحفوظ ظاهرًا.

## الاختبارات المنفذة
- `node --check` لكود الـ Worker واستخراج/فحص JavaScript اللوحة.
- اختبار محاكاة للـ Worker غطى:
  - نجاح سؤال على تقرير مملوك للمستخدم.
  - عدم تسريب `password` أو IP من مقتطف السجل إلى Prompt.
  - رفض جلسة غير صالحة بـ `CM-AI-401`.
  - غياب مفتاح Gemini يرجع `CM-AI-001` دون كسر التقرير.

## حالة النشر
- الكود مدفوع إلى GitHub، وواجهة اللوحة منشورة عبر GitHub Pages.
- نُشر الـ Worker بنجاح عبر GitHub Actions بعد إضافة أسرار نشر Cloudflare وتصحيح `CLOUDFLARE_ACCOUNT_ID` من زر النسخ داخل Cloudflare.
- التحقق الحي بتاريخ 2026-10-17 أعاد: `version:"0.5.0"` و`gemini_configured:true` و`configured:true`.
- طلب غير مصادق إلى `/v1/ai/report-chat` أعاد `CM-AI-401` كما هو متوقع.
- المتبقي لقبول الـ Pilot: سؤال حقيقي من المالك على تقرير محفوظ ظاهر في «تقاريري»، ومراجعة جودة الإجابة مقابل التقرير الحتمي.
