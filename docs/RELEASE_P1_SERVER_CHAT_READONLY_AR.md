# P1 — شات سيرفر عام للقراءة فقط

**التاريخ:** 2026-10-17  
**النطاق:** Worker `0.5.3` وواجهة `2026.10.17-ai3`.

## ما تم

- Endpoint جديد `POST /v1/ai/server-chat` بعد جلسة مستخدم سحابية وتحقق ملكية السيرفر.
- سياق الشات: حالة مشتقة من عمر النبضة (`ONLINE ≤150s`، `STALE 151–300s`، `OFFLINE >300s`، وسبات صريح)، بيئة السيرفر، البلجنات، آخر 5 تقارير، وآخر تنبيهات — بعد تنقية الأسرار.
- قسم «🤖 شات السيرفر» في اللوحة مع مبدّل سيرفر، شريط سياق، أسئلة مقترحة، إجابة، ودليل من السياق.
- أزرار شات في بطاقات السيرفر وتفاصيله، وتحويل تلقائي لشات السيرفر بعد نجاح ادعاء كود الربط.
- الشات يوضح أنه P1 قراءة فقط؛ أي طلب تعديل يتحول لشرح خطة آمنة دون ادعاء تنفيذ.

## اختبارات

- فحص Syntax للـ Worker وJavaScript اللوحة.
- محاكاة Worker: سيرفر مملوك يرجع حالة ONLINE وسياق تقرير، سيرفر غير مملوك يرجع `CM-AI-404`، ومقتطف السجل لا يسرب كلمة سر أو IP إلى prompt.

## حدود

- لا مهام ولا كتابة ملفات ولا تثبيت بلجنات في P1.
- قبول المالك الحقيقي للشات ما زال مطلوبًا بعد النشر، وقبول سؤال التقرير الأصلي يبقى بند P0 منفصلًا عند ظهور أي رمز خطأ جديد.
