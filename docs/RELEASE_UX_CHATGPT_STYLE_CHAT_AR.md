# UX — واجهة شات حديثة للسيرفر

**التاريخ:** 2026-10-17  
**النطاق:** واجهة `2026.10.17-ux2` فقط؛ لا تغيير في Worker أو البلجن.

## ما تغير

- شات السيرفر أصبح واجهة محادثة حديثة على نمط تطبيقات الذكاء الاصطناعي العامة، دون نسخ علامة أو اسم أي منتج:
  - رأس صغير فيه مبدّل السيرفر وحالته وآخر نبضة.
  - منطقة رسائل بفقاعات مستخدم ومساعد وأفاتار.
  - رسالة ترحيب واقتراحات قابلة للضغط ترسل فورًا.
  - مربع إرسال ثابت أسفل الشات وزر إرسال دائري.
  - Enter للإرسال وShift+Enter لسطر جديد، وتمدد تلقائي لمربع الكتابة.
  - مؤشر كتابة متحرك أثناء انتظار الإجابة.
  - دليل السياق يظهر مطويًا تحت رد المساعد.
  - محادثة منفصلة في الذاكرة لكل سيرفر أثناء الجلسة.

## حدود

- ما زال P1 قراءة فقط؛ شكل الشات الحديث لا يعني تفعيل تنفيذ.
- لا تُحفظ المحادثات سحابيًا في هذا الإصدار، ولا تُرسل كسياق إضافي للموديل بعد.
