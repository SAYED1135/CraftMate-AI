# UX — من الربط إلى الشات

**التاريخ:** 2026-10-17  
**النطاق:** واجهة `2026.10.17-ux1` فقط. لا تغيير في Worker أو البلجن أو منطق الربط السحابي.

## اختيارات المالك المنفذة

- بعد الدخول: شاشة بسيطة بزر واحد كبير «اربط سيرفرك» عند عدم وجود سيرفر مرتبط.
- خطوات الربط: Wizard خطوة واحدة في كل مرة.
- تحميل البلجن: زر مباشر لملف v0.4.0 + رابط GitHub Releases احتياطي.
- بعد الربط: شات سيرفر شبه كامل الشاشة مع شريط سياق ومبدّل سيرفر.

## التدفق الجديد

1. تسجيل/دخول.
2. إن لم يوجد سيرفر مرتبط: شاشة «اربط سيرفرك».
3. Wizard:
   - الاستضافة.
   - بيانات السيرفر.
   - طريقة الربط.
   - تحميل البلجن ورفعه إلى `plugins` ثم تشغيل/ريستارت السيرفر.
   - تشغيل `/craftmate link` وإدخال كود البلجن.
4. عند ادعاء الكود ونجاح الربط: تحويل تلقائي إلى شات السيرفر.
5. عند دخول لاحق وحساب به سيرفر مرتبط: فتح شات السيرفر مباشرة.

## ما لم يتغير

- كود البلجن v0.4.0 ومسار تسجيل الكود والادعاء التلقائي كما هما.
- اللوحة التفصيلية والتقارير والإعدادات ما زالت موجودة كأدوات ثانوية، لكنها ليست أول تجربة بعد الدخول.
- شات P1 ما زال قراءة فقط؛ لا ادعاء تنفيذ قبل مراحل المهام.
